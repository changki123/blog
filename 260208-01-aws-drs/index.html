AWS DRS 기반 재해복구 환경 구축 (진행 중)

2026-02-08
:: tags:  #AWS  #DRS  #Disaster Recovery  #Windows

진행 중인 프로젝트입니다.
현재 DRS 에이전트 설치 및 1:1 복제 테스트까지 완료했습니다.

목표

AWS DRS(Disaster Recovery Service)를 사용해 서울 리전의 Windows 서버를 홍콩 리전으로 재해복구 환경 구축

구성

Source Region: ap-northeast-2 (서울)
  └─ Windows Server
        │
        │ DRS 실시간 복제
        ▼
Target Region: ap-east-1 (홍콩)
  └─ Staging Server (대기 중)

완료된 작업

1. DRS 초기 설정

  • AWS DRS 콘솔에서 서비스 활성화
  • Source Region: 서울 (ap-northeast-2)
  • Target Region: 홍콩 (ap-east-1)

2. 에이전트 설치

  • Windows Server에 AWS Replication Agent 설치
  • 자동으로 데이터 복제 시작
  • 초기 동기화 완료

3. 1:1 스테이징 서버 생성 성공

  • 홍콩 리전에 복제된 서버 생성 확인
  • 데이터 복제 정상 동작 확인

다음 단계

  • N:N 다중 서버 동시 복구 테스트
  • 리전별 IP/네트워크 설정 자동화
  • Launch Template 구성 (초기화 스크립트)
  • 실제 Failover 테스트

AWS DRS란?

AWS Elastic Disaster Recovery는 온프레미스 또는 클라우드 서버를 다른 리전으로 실시간 복제하여 재해 발생 시 빠르게 복구할 수 있게 해주는 서비스입니다.

특징:

  • 실시간 블록 레벨 복제
  • RPO: 초 단위 (데이터 손실 최소화)
  • RTO: 10-15분 (빠른 복구)

진행률: 20% (에이전트 설치 및 1:1 복제 완료)
