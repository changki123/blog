AWS 온프레미스 마이그레이션 MGN (진행 중)

2026-02-11
:: tags:  #AWS  #MGN  #Migration  #Windows

진행 중인 프로젝트입니다.
현재 MGN 에이전트 설치 및 1:1 복제 테스트까지 완료했습니다.

목표

AWS MGN(Application Migration Service)을 사용해 서울 리전의 Windows 서버를 홍콩 리전으로 마이그레이션

구성

Source Region: ap-northeast-2 (서울)
  └─ Windows Server
        │
        │ MGN 실시간 복제
        ▼
Target Region: ap-east-1 (홍콩)
  └─ Staging Server (대기 중)

완료된 작업

1. MGN 초기 설정

  • AWS MGN 콘솔에서 서비스 활성화
  • Source Region: 서울 (ap-northeast-2)
  • Target Region: 홍콩 (ap-east-1)

2. 에이전트 설치

  • Windows Server에 AWS Replication Agent 설치
  • 자동으로 데이터 복제 시작
  • 초기 동기화 완료

3. 1:1 스테이징 서버 생성 성공

  • 홍콩 리전에 복제된 서버 생성 확인
  • 데이터 복제 정상 동작 확인

다음 단계

  • N:N 다중 서버 동시 마이그레이션 테스트
  • 리전별 IP/네트워크 설정 자동화
  • Launch Template 구성 (초기화 스크립트)
  • 실제 Cutover 테스트

AWS MGN이란?

AWS Application Migration Service는 온프레미스 또는 클라우드 서버를 AWS로 실시간 복제하여 다운타임 없이 마이그레이션할 수 있게 해주는 서비스입니다.

특징:

  • 실시간 블록 레벨 복제
  • 최소한의 다운타임으로 마이그레이션
  • 자동화된 전환 프로세스

진행률: 20% (에이전트 설치 및 1:1 복제 완료)
