## 목표

AWS MGN(Application Migration Service)을 사용해 서울 리전의 Windows 서버를 홍콩 리전으로 마이그레이션

<!-- more -->

---

## 구성
```
Source Region: ap-northeast-2 (서울)
  └─ Windows Server
        │
        │ MGN 실시간 복제
        ▼
Target Region: ap-east-1 (홍콩)
  └─ Staging Server (대기 중)
```

---

## 완료된 작업

### 1. MGN 초기 설정
- AWS MGN 콘솔에서 서비스 활성화
- Source Region: 서울 (ap-northeast-2)
- Target Region: 홍콩 (ap-east-1)

### 2. 에이전트 설치
- Windows Server에 AWS Replication Agent 설치
- 자동으로 데이터 복제 시작
- 초기 동기화 완료

### 3. 1:1 스테이징 서버 생성 성공
- 홍콩 리전에 복제된 서버 생성 확인
- 데이터 복제 정상 동작 확인

## AWS MGN이란?

**AWS Application Migration Service**는 온프레미스 또는 클라우드 서버를 AWS로 **실시간 복제**하여 다운타임 없이 마이그레이션할 수 있게 해주는 서비스입니다.

**특징:**
- 실시간 블록 레벨 복제
- 최소한의 다운타임으로 마이그레이션
- 자동화된 전환 프로세스
