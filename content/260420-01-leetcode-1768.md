## 문제

[1768. Merge Strings Alternately](https://leetcode.com/problems/merge-strings-alternately/)

두 문자열 `word1`과 `word2`가 주어졌을 때, 두 문자열을 번갈아가며 합친 결과를 반환하는 문제다.  
`word1`부터 시작해서 한 글자씩 번갈아 추가하고, 한쪽이 먼저 끝나면 나머지 문자열을 그냥 뒤에 붙이면 된다.

**예시:**
```
word1 = "abc", word2 = "pqr" → "apbqcr"
word1 = "ab",  word2 = "pqrs" → "apbqrs"
word1 = "abcd", word2 = "pq"  → "apbqcd"
```

## 풀이

Rust로 처음 풀어본 문제다. Python이었으면 인덱스로 접근했겠지만, Rust에서는 String을 직접 인덱싱할 수 없어서 `.chars()`로 이터레이터를 만들어 접근했다.

핵심 아이디어는 간단하다:

1. 두 문자열 중 긴 쪽 길이 × 2만큼 루프를 돈다
2. 짝수 인덱스면 `word1`에서, 홀수 인덱스면 `word2`에서 문자를 가져온다
3. `if let Some(c)`로 이터레이터가 끝났는지 확인하고, 있을 때만 추가한다

```rust
impl Solution {
    pub fn merge_alternately(word1: String, word2: String) -> String {
        let mut a1 = word1.chars();
        let mut a2 = word2.chars();

        let mut result = String::new();
        let mut cnt = 0;

        if word1.len() > word2.len() {    
            cnt = word1.len() * 2;
        } else {
            cnt = word2.len() * 2;
        }

        for i in 0..cnt {
            if i % 2 == 0 {
                if let Some(c) = a1.next() {
                    result.push(c);
                }
            } else {
                if let Some(c) = a2.next() {
                    result.push(c);
                }
            }
        }
        
        return result;
    }
}
```

## Rust에서 배운 것

**`chars()`와 이터레이터**

Rust의 `String`은 UTF-8로 인코딩되어 있어서 바이트 인덱스로 직접 접근하면 문자가 깨질 수 있다.  
그래서 문자 단위로 순회하려면 `.chars()`를 사용해야 한다.

`.chars()`는 `Iterator`를 반환하고, `.next()`를 호출하면 `Option<char>`가 나온다.

**`if let Some(c)`**

Rust에서 `Option`을 처리할 때 쓰는 패턴이다.  
이터레이터가 아직 남아있으면 `Some(c)`로 문자를 꺼내고, 끝났으면 아무것도 안 한다.

```rust
if let Some(c) = a1.next() {
    result.push(c);  // 문자가 있을 때만 실행
}
```

**`String::new()`와 `.push()`**

빈 문자열을 만들고 문자를 하나씩 추가할 때 `push(char)`를 사용한다.  
문자열을 붙이려면 `push_str(&str)`를 쓴다.

Runtime과 Memory 모두 무난하게 통과했다.

Easy 난이도답게 로직 자체는 단순한데, Rust 문법에 익숙하지 않다 보니 "문자열을 어떻게 순회하지?"부터 찾아봐야 했다.
