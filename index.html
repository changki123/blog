SRV 레코드란?

SRV(Service) 레코드는 특정 서비스의 위치 정보를 제공하는 DNS 레코드 타입임. 일반적인 A 레코드가 도메인을 IP 주소로 연결한다면, SRV 레코드는 서비스의 호스트명과 포트 정보까지 함께 제공할 수 있음.

Pre-signed URL이란?

S3 버킷을 private으로 유지하면서도, 특정 파일에 대해 임시 접근 권한을 부여하는 URL입니다.

핵심 포인트:

  • S3 버킷은 비공개 상태 유지
  • URL을 아는 사람만 제한 시간 동안 접근 가능
  • 시간 지나면 자동으로 차단
